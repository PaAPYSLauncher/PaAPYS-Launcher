PaAPYS Launcher
📖 О проекте
PaAPYS Launcher — это современный, быстрый и визуально отполированный лаунчер для Minecraft. Клиент сочетает в себе глубокую кастомизацию сборок, аппаратный 3D-рендеринг скинов, внутриигровой оверлей и сетевые возможности для комфортной игры без лишнего софта.

✨ Ключевые особенности
🎨 macOS Liquid Glass UI: Темный стеклянный интерфейс на базе CustomTkinter с акцентными темами (Apple Blue, Neon Emerald, Cyber Purple, Sunset Orange).

🧍 Интерактивный 3D-скин: Вращение модельки на 360° мышью, отображение слоев одежды и анимация походки на базе Three.js / WebGL.

💬 Реальный WebSocket-чат: Сетевой обмен сообщениями в реальном времени с поддержкой каналов (#общий, #поиск-тимейтов, #моды-и-сборки).

⚡ PaAPYS Game Overlay: Внутриигровой полупрозрачный HUD с чатом, часами, мониторингом сессии и быстрым доступом к скриншотам.

📦 Каталог Modrinth & Модпаки: Поиск и скачивание модов, ресурспаков и шейдеров прямо внутри приложения.

🧩 Умный менеджер модов: Включение и отключение модов в один клик через безопасное переименование в .disabled.

🎮 Discord Rich Presence: Динамическое отображение статуса игры, выбранной сборки и времени в профиле Discord.

🖥 Локальный сервер: Автоматическое скачивание ядер (Purpur / Vanilla), настройка портов, offline-режима и встроенная консоль управления.

🛠 Стек технологий
GUI: customtkinter, Pillow

Ядро запуска: minecraft-launcher-lib

3D & Web: pywebview, Three.js, skinview3d

Сеть & API: websocket-client, requests

Интеграции: pypresence (Discord RPC)

Медиа: moviepy (генератор промо-трейлеров)
